Ghi chú tính năng

  1. Đầu mục + chấm sáng. Giữ chuột lên text ~0.25s rồi kéo → mục “nhấc lên” (bóng đổ, nghiêng nhẹ), các mục khác trượt lên/xuống mượt nhường chỗ. Click vào chấm để bật/tắt: xanh lá = enable, trắng xám = disable.
  2. Hover → hiện + (thêm mục ngay dưới) và − (xoá, có hộp xác nhận).
  3. Text: chữ trắng, Ctrl+B in đậm, Ctrl+K chèn link → chữ xanh dạ quang. Ctrl+Click để mở link.
  4. Mục con: thụt vào, chữ trắng mờ. Kéo thả được trong nhóm cha (đi theo cha khi cha di chuyển).
  5. 2 loại mục con: có ô check ☐ (tick xong → gạch ngang) hoặc chỉ là chấm •.
  6. Ảnh JPG/PNG: nút Ảnh, kéo thả file vào, hoặc Ctrl+V. Đặt tự do trên canvas, kéo góc để scale.
  7. Lưu / Mở file .mkeep (1 file duy nhất, ảnh được nhúng bên trong) + tự động lưu.
